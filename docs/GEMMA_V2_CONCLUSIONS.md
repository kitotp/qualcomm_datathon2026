**Другой подход, который имеет смысл рассмотреть. Это гипотеза, а не проверенный результат.**

Перенести часть рассуждения из свободного текста модели в исполняемый и проверяемый процесс:

`условие → модель выбирает тип задачи и строит короткий план → Python/решатель выполняет план → проверка ограничений → объяснение по проверенным шагам`

Для первого прототипа достаточно нескольких ограниченных типов задач: равные количества после передачи предметов, скорость/время/расстояние, доли и проценты, линейные уравнения, небольшой перебор. Модель возвращает структуру с типом задачи, параметрами и ссылками на исходные числа. Программа выполняет разрешённую операцию и проверяет ограничения. Свободное выполнение сгенерированного Python для этого не требуется.

Например, для передачи конфет от человека с 17 конфетами человеку с 9 модель должна выбрать схему уравнивания. Программа вычислит `(17 - 9) / 2 = 4` и проверит `9 + 4 == 17 - 4`. Затем ответ сопоставляется с вариантом, а объяснение строится из этих же шагов. Правильность вычисления не гарантирует правильность выбранной схемы: соответствие плана условию тоже нужно отдельно проверять.

Банк проверенных схем и решений можно использовать как опору для выбора плана. Сложные задачи, рисунки и неподдерживаемые типы нельзя насильно сводить к знакомой схеме. В учебном режиме для них нужен честный ответ о недостатке данных или неподтверждённом решении. Контракт соревнования с обязательной буквой следует держать отдельно.

Для разбора ошибки ученика нужны его шаги. По одной неправильной букве нельзя достоверно установить причину ошибки. Если есть только буква, можно предложить проверенный следующий шаг, но нельзя утверждать, что ученик «перепутал знак» или «неправильно поделил».

Проверять такой подход следует на новых задачах отдельно по этапам: извлечение данных, выбор схемы, выполнение, итоговый ответ и ложные указания на ошибки ученика. Пока эти проверки не пройдены, обещать надёжные объяснения или конкретную accuracy нельзя. Никаких новых экспериментов в рамках остановленного запуска не выполняется.
